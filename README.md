# Лабораторная работа № 3 — «Доска публикаций»

## Запуск

Серверная часть не нужна. Достаточно открыть `index.html` в браузере
(двойным щелчком или через Live Server в VS Code). Нужен доступ в интернет:
данные берутся с https://jsonplaceholder.typicode.com.
Может понадобиться использование VPN.

## Файлы

- `index.html`
- `style.css`
- `app.js`

## Результаты проверки

| Сценарий | Результат |
|---|---|
| Нажатие «Загрузить публикации» | Появились 5 публикаций с заголовком и текстом, сообщение «Загружено публикаций: 5» |
| Пустые поля или одни пробелы | Под полями ошибки, запрос не отправляется |
| Корректные заголовок и текст | Ответ HTTP 201, сообщение с заголовком и ID (101), публикация добавлена в начало списка |
| Адрес GET заменён на `/postz` (404) | Сообщение «Ошибка сервера: 404», кнопка снова активна; адрес восстановлен |

JSONPlaceholder только имитирует создание записей: на сервере они не сохраняются,
поэтому после повторной загрузки списка новая публикация не появится.
